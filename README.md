# ダイノラン

Chrome のオフライン恐竜ゲーム風の、横スクロールのランゲーム(PWA)です。自動で走る恐竜をタップでジャンプさせ、サボテンや岩をよけて、ゴールの旗を目指します。全10ステージで、進むほど速く・むずかしくなります。

- 公開 URL: https://mmishina-art.github.io/simple_dino/
- スマホのホーム画面に追加すると、アプリとして、オフラインでも遊べます(最初の画面の「アプリとしてインストールする方法」を参照)。

## 遊び方

- 画面のどこをタップしても、ジャンプします(パソコンはスペースキー / ↑ / W)。
- **押し続けると高く、すぐ離すと低く**跳べます。高い岩は、しっかり押し続けないと越えられません。
- 障害物にぶつかるとゲームオーバー。「もういちど」で、すぐに同じステージを再挑戦できます。
- ステージは最初の画面から選びます。はじめはステージ1だけで、**クリアすると次のステージが遊べる**ようになります(クリア済みは ★、まだは 🔒)。クリア済みのステージは、何度でも遊べます。
- 進み具合(どこまでクリアしたか、挑戦回数)は、この端末の中に自動で保存されます。「記録のバックアップ」でファイルに書き出して、消えたときに戻せます。
- **全10ステージをクリアすると、エンディング**が見られます(あとから、ステージ選択の画面で見直せます)。

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm run verify       # lint → test → build → check:dist
npx playwright install chromium && npm run test:e2e
```

ルールの詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `src/logic.ts` | ゲームのルール(ジャンプの物理、当たり判定、1フレームの進め方)。DOM に触れない純関数 |
| `src/stages.ts` | 全10ステージのデータ(速さと、障害物の配置) |
| `src/sprites.ts` | ドット絵(文字の並びで自作) |
| `src/themes.ts` | ステージごとの背景の色と飾り |
| `src/render.ts` | Canvas への描画 |
| `src/play.ts` | プレイ中の進行(1/60 秒の固定ステップ、入力) |
| `src/progress.ts` | どこまでクリアしたかの記録と、ステージの解放のルール(純関数) |
| `src/ending.ts` | エンディング画面の動き(`render.ts` の `drawEnding` で描く) |
| `src/main.ts` | 画面の切り替え(ステージ選択、ゲーム、結果) |
| `src/sound.ts` | 効果音(Web Audio で合成。音声ファイルは持たない) |
| `tests/solver.ts` | ステージが「解ける」ことを確かめる、総当たりのソルバー(テスト用) |

## ステージの難しさを変えるとき

ステージの配置は `src/stages.ts` の文字列です(`S`・`B`・`R`・`T` が障害物、数字が進む時間のミリ秒)。変えたら `npm test` を実行します。`tests/stages.test.ts` が、すべてのステージで

- ジャンプの押し方を総当たりして、クリアできること
- 判定を何 px 厳しくしても解けるか(「ゆとり」)が、前半は大きく、最終ステージは「かなり難しいが、人間の操作でできる」範囲に入っていること

を確かめます。

## ライセンス・素材

画像・音・文章は、すべてこのアプリのために自作したものです(絵は文字の並びから Canvas で描き、音は Web Audio で合成しています)。外部のフォント・ライブラリ・画像は使っていません。
