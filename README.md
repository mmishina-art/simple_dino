# ダイノラン

Chrome のオフライン恐竜ゲーム風の、横スクロールのランゲーム(PWA)です。自動で走る恐竜をタップでジャンプさせ、サボテンや岩をよけて、ゴールの旗を目指します。全10ステージで、進むほど速く・むずかしくなります。

- 公開 URL: https://mmishina-art.github.io/simple_dino/
- スマホのホーム画面に追加すると、アプリとして、オフラインでも遊べます(最初の画面の「アプリとしてインストールする方法」を参照)。

## デバッグモード

タイトル画面の、いちばん下のバージョン表示(`v1.x.x`)を、3 秒以内に 7 回タップすると、オン/オフが切り替わります(隠しコマンド)。オンの間は、ちびダイノと全ステージを、クリアしなくても選べます(見た目や操作感を試すため)。ステージ選択に「デバッグモード」と出ます。同じ操作でオフにすると、もとの解放状態にもどります。バックアップのファイルには入りません。オンの間は、ゲーム画面の左下に、フレームの時間(FPS・最悪のフレーム・「遅れ」の割合・処理時間)が出ます。カクつきを実機で調べるためのものです。この表示をタップすると、描き方(画面の密度: 自動 / ×2 / ×1 / 描かない)が切り替わり、数字がどう変わるかで、原因を切り分けられます。

## 遊び方

- 画面のどこをタップしても、ジャンプします(パソコンはスペースキー / ↑ / W)。
- **押し続けると高く、すぐ離すと低く**跳べます。高い岩は、しっかり押し続けないと越えられません。
- 障害物にぶつかるとゲームオーバー。「もういちど」で、すぐに同じステージを再挑戦できます。
- 失敗したときは、**どこまで進んだか(%)**と、そのステージの**ベスト**が出ます。進み具合の棒には、ベストの場所に印が付きます。
- 各ステージに、たまご(3〜5個)が浮かんでいます。ジャンプの頂点付近や、着地する地面の上にあります。取れなくてもクリアはできます。
- ★は、ステージごとに最大3つです。★1: クリアする / ★2: たまごを全部取る(何回かに分けて取った合計でよい) / ★3: 1回のクリアで、たまごを全部取る。
- ぎりぎりで障害物を越えると、キラキラと「ぎりぎり!」が出ます。着地やジャンプでは土ぼこりが立ち、やられると画面がゆれ、クリアすると紙ふぶきが降ります(動きを減らす設定のときは出しません)。
- ステージ選択の画面の下に、**エンドレスモード**があります(最初から遊べます)。ゴールがなく、障害物が終わりなく出てきます。走るほど速くなり、250 m ごとに背景が変わります(10 種類をぐるぐる)。専用の曲が流れます。
- 全 10 ステージをクリアすると、**ちびダイノ**が遊べるようになります(ステージ選択の上で、キャラを選びます)。同じコースを、速さ ×1.4・当たり判定が小さい(14×16)で走ります。前半は同じくらい、後半ほど速さのぶん難しくなります。記録(クリア・★)はキャラごとに別です。エンドレスはダイノだけです。
  - 途中に**肉**(🍖)が浮かんでいます。取ると**レベルが1上がり**(最大3)、レベルが高いほど**速くなり**(1レベルあたり +8%)、**スコアの倍率が上がります**(×1.5 / ×2.0 / ×2.5)。レベルは約8秒で1つ下がります(肉をまた取ると、時間がもどります)。曲のテンポも少し速くなります。
  - 肉は、地面(すきまの中ほど)や、障害物の上、ジャンプの前後など、ちょっと危ない所にあります。取らなくても進めるので、「取って稼ぐか、避けて安全に行くか」を選べます。
  - スコアは「点」(走った距離 m × そのときの倍率)で、ハイスコアが保存されます。結果の画面には、走った距離、取った肉の数、最高の倍率も出ます。
- 最初はタイトル画面です。「あそぶ」でステージ選択に進みます。
- ステージはステージ選択の画面から選びます。はじめはステージ1だけで、**クリアすると次のステージが遊べる**ようになります(クリア済みは ★、まだは 🔒)。クリア済みのステージは、何度でも遊べます。
- 進み具合(どこまでクリアしたか、挑戦回数)は、この端末の中に自動で保存されます。「記録のバックアップ」でファイルに書き出して、消えたときに戻せます。
- **全10ステージをクリアすると、エンディング**が見られます(あとから、ステージ選択の画面で見直せます)。

## 音楽(BGM)

タイトル、エンディング、エンドレス、全10ステージに、それぞれ別の曲があります(草原は明るく、砂漠はエキゾチックに、洞窟はやまびこ、火山は力強く、宇宙は夢のように、最終ステージは速く激しく)。ゲームを始める前に曲が止まり、「もういちど」でステージの曲が頭から鳴ります。

- 曲はすべて、このアプリのために作ったオリジナルです。音声ファイルは使わず、Web Audio で合成して演奏しています(`src/songs.ts` にメロディーとコード、`src/music.ts` に演奏)。
- BGM は、効果音とは別にオン/オフできます(タイトル画面とゲーム中の 🎵 ボタン)。設定は端末に保存されます。
- ブラウザの決まりで、最初のタップまで音は出ません。

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm run verify       # lint → test → build → check:dist
npx playwright install chromium && npm run test:e2e
```

ルールの詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `src/logic.ts` | ゲームのルール(ジャンプの物理、当たり判定、1フレームの進め方)。DOM に触れない純関数 |
| `src/stages.ts` | 全10ステージのデータ(速さと、障害物の配置) |
| `src/sprites.ts` | ドット絵(文字の並びで自作) |
| `src/themes.ts` | ステージごとの背景の色と飾り |
| `src/render.ts` | Canvas への描画 |
| `src/characters.ts` | 遊べるキャラ(ダイノ・ちびダイノ)の速さ・当たり判定の大きさ。ステージをキャラ用の形にする |
| `src/endless.ts` | エンドレスモードのコース作り(障害物の「部品」と肉を、乱数でつなぐ)と、速さ・背景・スコアの決め方 |
| `src/fx.ts` | 演出の粒(土ぼこり・キラキラ・紙ふぶき)とふきだし、画面のゆれ(見た目だけ) |
| `src/play.ts` | プレイ中の進行(1/60 秒の固定ステップ、入力) |
| `src/progress.ts` | どこまでクリアしたか・ベストの進み具合・取ったたまご・★の記録と、ステージの解放のルール(純関数) |
| `src/ending.ts` | タイトル・エンディング画面の絵の動き(`render.ts` の `drawTitle` / `drawEnding` で描く) |
| `src/main.ts` | 画面の切り替え(ステージ選択、ゲーム、結果) |
| `src/sound.ts` | 効果音(Web Audio で合成。音声ファイルは持たない) |
| `src/songs.ts` | BGM の曲のデータ(メロディー・コード・リズム)と、演奏イベントを作る純関数 |
| `src/music.ts` | BGM の演奏(先読みして音を予約する) |
| `tests/solver.ts` | ステージが「解ける」こと(たまごを全部取る経路や、エンドレスのコースも)を確かめる、総当たりのソルバー(テスト用) |

## ステージの難しさを変えるとき

ステージの配置は `src/stages.ts` の文字列です(`S`・`B`・`R`・`T` が障害物、数字が進む時間のミリ秒)。変えたら `npm test` を実行します。`tests/stages.test.ts` が、すべてのステージで

- ジャンプの押し方を総当たりして、クリアできること
- 判定を何 px 厳しくしても解けるか(「ゆとり」)が、前半は大きく、最終ステージは「かなり難しいが、人間の操作でできる」範囲に入っていること

を確かめます。

## ライセンス・素材

画像・音・曲・文章は、すべてこのアプリのために自作したものです(絵は文字の並びから Canvas で描き、効果音と BGM は Web Audio で合成しています)。外部のフォント・ライブラリ・画像は使っていません。

## エンドレスの部品を変えるとき

部品は `src/endless.ts` の `CHUNKS`(障害物の記号と、ミリ秒のすきま)です。足したり変えたりしたら `npm test` を実行します。`tests/endless.test.ts` が、すべての部品を、その部品が出る速さで、ソルバーで確かめます(越えられない部品は、テストが落ちます)。部品どうしは、1 秒前後のすきまをあけてつなぐので、どの順番でつないでも越えられます。コース全体(だんだん速くなる)も、複数の種で通しで確かめます。

**肉で速くなっても越えられること**も、同じように確かめます(いちばん速いレベルの倍率で、全部品と、コース全体。肉のレベルが、ずっと3・行き来する・でたらめに上がり下がりする、のどれでも)。肉の置き場所も、全部の肉について「障害物をよけながら取れる経路がある」ことを確かめます。部品を足すときは、速くなった状態でも越えられるかに気をつけてください(すきまが短い部品は、テストが落ちます)。
